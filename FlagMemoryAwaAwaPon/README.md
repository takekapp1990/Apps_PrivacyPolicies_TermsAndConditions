# 国旗の暗記 あわあわポン — LP

2026-11-02に、現在のアプリの学習・復習・8ゲーム・世界の国図鑑・世界の国だより・学習プラスに合わせて更新。

## 更新方法

リポジトリのルートで実行します。Pythonの標準ライブラリだけで生成できます。

```sh
python3 scripts/build_flag_memory_landing.py
python3 scripts/validate_flag_memory_landing.py
```

- 原稿: `scripts/flag_memory_lp_copy/*.json`（10言語）
- HTML: `FlagMemoryAwaAwaPon/<言語>/landing_page_<言語>.html`（生成物）
- 共通デザイン・動作: `landing.css`、`landing.js`
- 規約・プライバシーポリシー: 日本語と英語のHTMLを直接編集。共通デザインは`legal.css`。
- アプリの実画面: `images/lp/<言語>/screen-01.webp`〜`screen-06.webp`。学習・国旗クイズ・そっくり国旗・国図鑑・記録・ゲーム選択の順。記録画面はサンプルデータ。
- SNS共有画像: `images/lp/og/<言語>.png`（1200×630）。原稿・画面画像を変えた場合は、共有画像も合わせて見直します。

無料枠、動画による追加枠、サブスクリプション、トライアル、広告・同意の説明は、アプリ実装と照合して更新してください。価格は地域・ストアにより変わるため固定金額を掲載していません。旧買い切り権利と現在の学習プラスは別の商品です。

静的HTMLなのでJavaScriptなしでも紹介文・料金説明・ストアリンクを読めます。画面切り替えと例題にはJavaScriptを使います。既存のストアクリック計測を使用し、LPのGoogle Analyticsは`takekapp.com`上だけで読み込みます。

`http://127.0.0.1:8743/FlagMemoryAwaAwaPon/ja/landing_page_ja.html`を開きます。ルート相対の共通計測スクリプトを使うため、ファイルの直接表示よりHTTPでの確認を推奨します。

公開はこのリポジトリの既存GitHub Pages運用に従います。HTML生成やローカル確認だけでは公開されません。

## LP間の共通ルールと文章

KVとページ末尾にApp Store・Google Playの公式バッジを表示します。KVでは直接ストアへ移動できるようにし、バッジを遅延読み込みしません。共通のストアクリック計測で`hero`と`download`を区別します。言語切り替え、無料ダウンロードとアプリ内課金の表記、規約・プライバシーポリシー・お問い合わせへのリンクも確認します。

見出しは機能や使い方がわかる言葉にします。短いキャッチコピーを句点で並べたり、「〜を、〜に」のように読点で演出したりしません。本文は必要な情報を自然な文で説明します。翻訳でもこの方針を守り、各言語の文法に必要な句読点は使います。原稿を変えたときはHTMLだけでなく共有画像とアプリ一覧の紹介文も合わせて更新します。

App Storeのリンクは`build_flag_memory_landing.py`の`APP_STORE_COUNTRIES`で管理し、KVと末尾の両方に反映します。対応はja→jp、en→us、es→es、de→de、ko→kr、th→th、id→id、fr→be（`?l=fr-FR`）、pt-BR→br、zh-Hant→tw。検証スクリプトで言語とリンク先の一致も確認します。

フランス向け`/fr/`は2026-11-02の確認で404。フランス語版は正常に開けるベルギーのフランス語ストアを指定しています。フランスでの公開状況が変わった場合はリンク先を再確認してください。
