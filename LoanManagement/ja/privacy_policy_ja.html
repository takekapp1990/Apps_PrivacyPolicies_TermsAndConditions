「わたしの住宅ローン管理」プライバシーポリシー

最終更新日：2026年9月20日

このプライバシーポリシーは、takekapp1990（以下「運営者」といいます。）が提供するアプリケーションサービス「わたしの住宅ローン管理」（以下「本アプリ」といいます。）におけるユーザー情報の取扱いを定めるものです。

ユーザーは、本アプリを利用する前に本ポリシーをよくお読みください。ユーザーが本アプリを利用した時点で、本ポリシーに同意したものとみなします。

第1条（取得する情報）

1. ユーザーが入力する情報

運営者は、ユーザーが本アプリで入力した住宅ローン、自動車ローン、奨学金、カードローン、キャッシング、リボ払い等のローン情報、返済条件、残高、履歴情報、設定情報、メモ情報、コミュニティ投稿内容、アンケート回答内容、お問い合わせ内容等を取得または保存することがあります。

共有コード、借り換え見守り又はFP相談をユーザーが選択した場合には、各画面で表示される対象情報及び同意情報を取得または保存することがあります。これらの機能を利用しない限り、端末内のローン情報が当該目的で自動送信されることはありません。

2. 端末上で扱う情報

本アプリは、利便性向上のために端末内ストレージ上へ設定情報や保存済みデータを保持することがあります。また、生体認証ロックの有効化状態等、端末の認証関連設定を参照する場合があります。

3. 本アプリの利用に伴い自動取得される情報

運営者は、本アプリの利用状況、端末情報、OS情報、クラッシュ情報、ログ情報、通知に必要な情報、匿名認証により発行される識別子、広告識別子その他本アプリの運営・改善・広告表示に必要な情報を自動的に取得する場合があります。

4. 外部サービスが取得する情報

本アプリでは、サービス運営・改善・広告表示のために以下の外部サービスを利用しています。

  • Firebase Analytics
  • Firebase Crashlytics
  • Firebase Remote Config
  • Firebase Authentication（匿名認証を含む）
  • Firebase App Check
  • Cloud Firestore
  • Cloud Functions for Firebase
  • Firebase Cloud Messaging
  • Google AdMob
  • RevenueCat
  • Apple App Store又はGoogle Playのアプリ内課金サービス

本アプリでは、ログインなしで利用できる機能の提供、不正利用防止及び購入状態の管理のため、Firebase又はRevenueCatが発行する匿名の識別子を利用する場合があります。また、広告配信のために、広告配信サービスが広告識別子、IPアドレス、端末情報、利用状況等を取得・利用する場合があります。

これらのサービスにより取得・処理される情報の取扱いについては、各事業者の関連ポリシーもご確認ください。

  • Google プライバシーポリシー
  • Googleのサービスを使用するサイトやアプリから収集した情報の使用
  • RevenueCat Privacy Policy

第2条（利用目的）

運営者は、取得した情報を以下の目的で利用します。

  • 本アプリの提供、維持、改善のため
  • ローン試算、保存、表示、再編集等の機能提供のため
  • コミュニティ機能、アンケート機能、通知機能の提供のため
  • 共有コードの発行、受け取り、無効化及び不正利用防止のため
  • ユーザーの同意に基づく借り換え見守り、判定及びアプリ内通知のため
  • FP相談の受付、連絡、回答及び相談対応のため
  • アプリ内購入の処理、購入状態の確認、復元及び不正購入防止のため
  • 利用状況分析、不具合調査、品質向上のため
  • お問い合わせ対応、重要なお知らせの通知のため
  • 不正利用防止、モデレーション対応のため
  • 広告の表示、広告配信の最適化、広告効果の測定のため

第3条（コミュニティ機能に関する取扱い）

本アプリのコミュニティ機能を利用した場合、投稿内容、返信内容、通報内容、アンケート内容その他関連情報が外部サーバーに保存され、他のユーザーまたは運営によって閲覧・確認される場合があります。

運営者は、利用規約やガイドラインに反する可能性がある投稿について、確認、非表示、削除、制限その他必要な対応を行うことがあります。また、通報対応、違反確認、安全な運営、不正利用対策のため、必要な情報を保存する場合があります。

第4条（共有、借り換え見守り及びFP相談）

1. 共有コード

ユーザーが共有コードを発行した場合、選択したローン情報は暗号化された通信によりサーバーへ送信されます。共有コードの有効期間は原則として発行から24時間です。受け取り完了後は共有用データを削除し、発行者は有効期間内であっても共有を無効化できます。削除処理や不正利用防止に必要な最小限の記録は、システム上の処理に伴い一定期間残る場合があります。

2. 借り換え見守り

借り換え見守りは、ユーザーが画面上で同意して有効にした場合に限り、ローン名、現在残高、金利、残り期間、金利区分、残高確認日等の判定に必要な情報をサーバーへ送信します。見守りを無効にした場合、見守り対象ローン及び受信箱の情報を削除しますが、無効化状態、不正利用防止情報、法令上又は運用上必要なログが残る場合があります。

3. FP相談

FP相談は提携先の案内を含むPR機能です。ユーザーが送信前の確認画面で同意して送信した場合に限り、氏名、メールアドレス、相談希望度、相談テーマ、メッセージ及び送信経路を取得します。ローン情報の共有を選択した場合には、ローン名、金融機関名、残高、当初借入額、金利、返済期間等も取得しますが、返済履歴や家計情報は共有対象に含めません。

第5条（アプリ内購入及び広告）

本アプリは、プレミアム永久版の購入状態を確認し、購入又は復元を提供するためRevenueCat並びにApple App Store又はGoogle Playの課金サービスを利用します。RevenueCatには匿名のApp User ID、購入履歴、商品情報、レシート又は購入状態に関する情報が送信される場合があります。運営者及びRevenueCatが、ユーザーのクレジットカード番号等の決済手段情報を本アプリから直接取得することはありません。

無料版ではGoogle AdMobによるバナー広告又はリワード広告を表示する場合があります。広告配信では広告識別子、IPアドレス、端末情報、広告の表示・操作情報等がGoogleその他の広告配信事業者により取得・利用される場合があります。プレミアム永久版では、アプリの仕様に従い広告表示が停止されます。

第6条（第三者提供及び委託）

運営者は、法令に基づく場合その他正当な理由がある場合を除き、個人情報をユーザーの同意なく第三者に提供しません。ただし、本アプリの提供に必要な範囲で外部サービス事業者に情報処理を委託する場合、又はユーザーがFP相談の連絡・対応に同意したうえで送信した情報を相談対応を担当する提携先へ必要な範囲で提供する場合があります。

第7条（保存期間および削除）

運営者は、取得した情報を利用目的の達成に必要な期間、または法令上必要な期間保存します。端末内保存データは、アプリ削除、端末変更、故障その他の事情により失われる場合があります。

情報の確認、削除その他のご相談を希望する場合は、お問い合わせ先までご連絡ください。ご依頼の内容、情報の種類、保存状況等により、対応できない場合があります。

第8条（安全管理）

運営者は、取得した情報への不正アクセス、漏えい、滅失または毀損の防止その他安全管理のため、合理的な範囲で必要かつ適切な措置を講じます。

第9条（本ポリシーの変更）

運営者は、必要に応じて本ポリシーを変更できるものとします。変更後の内容は、本アプリまたは運営者が管理するウェブサイトに掲載した時点から効力を生じます。
