So funktioniert es

Suchen Sie nach einer Zelle innerhalb einer Zeile, Spalte oder eines Blocks, wo eine bestimmte Zahl nur an einem Ort passen kann.

Wenn es nur eine Zelle gibt, die eine bestimmte Zahl enthalten kann, ist diese Zahl für diese Zelle bestimmt.

Beispiel

Häufige Fehler

Prüfe alle leeren Felder der gewählten Gruppe. Die Zahl darf dort nur eine mögliche Position haben.
