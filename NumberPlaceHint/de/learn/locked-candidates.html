So funktioniert es

Wenden Sie diese Technik an, wenn die für eine bestimmte Zahl in Frage kommenden Zellen eines Blocks alle auf derselben Linie (Zeile oder Spalte) liegen.

In diesem Block muss die Zahl also definitiv irgendwo auf dieser Linie platziert werden.

Daraus folgt, dass Sie jene Zahl aus den Kandidaten-Notizen der „Zellen anderer Blöcke“ entfernen dürfen, welche sich auf der gleichen Zeile (oder Spalte) befinden.

Wenden Sie dies an, wenn sich die in Frage kommenden Zellen für eine Zahl in einer Zeile (bzw. Spalte) alle innerhalb ein und desselben Blocks konzentrieren.

In dieser Zeile (oder Spalte) wird die Zahl auf jeden Fall irgendwo innerhalb dieses Blocks stehen.

Daher können Sie jene Zahl aus den Kandidaten-Notizen der „Zellen in anderen Zeilen (oder Spalten)“ löschen, sofern sie exakt in diesem Block liegen.

Beispiel

Häufige Fehler

Prüfe alle Positionen eines Kandidaten. Pointing entfernt außerhalb des Blocks, Claiming an anderen Stellen innerhalb des Blocks.
