Candidats Bloqués

Utilisez cette méthode lorsque les cases candidates pour un chiffre dans un bloc sont alignées sur une seule ligne (ligne ou colonne).

Principe

Utilisez cette méthode lorsque les cases candidates pour un chiffre dans un bloc sont alignées sur une seule ligne (ligne ou colonne).

Dans ce bloc, le chiffre doit obligatoirement se trouver quelque part dans cette ligne.

Par conséquent, vous pouvez supprimer ce chiffre des notes de candidats des "cases des autres blocs" qui sont dans la même ligne (ou colonne).

Utilisez cette méthode lorsque les cases candidates pour un chiffre dans une ligne (ou colonne) sont concentrées dans un seul bloc.

Dans cette ligne (ou colonne), le chiffre doit obligatoirement se trouver quelque part dans ce bloc.

Par conséquent, vous pouvez supprimer ce chiffre des notes de candidats des "cases des autres lignes (ou colonnes)" qui sont dans le même bloc.

Erreurs fréquentes

Vérifiez toutes les positions du candidat. Pointing supprime hors du bloc ; Claiming supprime ailleurs dans ce bloc.
