How it works

Consider the candidate numbers that could fit in an empty cell.

By excluding numbers already present in the same row, column, or block, only one possibility remains.

That number is then determined for the cell.

Common mistakes

A lone note is reliable only if no candidates have been left out. Check the notes before confirming the number.
