How it works

Use this when candidate cells for a number within a block are aligned in a single line (row or column).

In this block, the number must definitely go somewhere in this line.

Therefore, you can remove that number from the candidate notes of "cells in other blocks" that are in the same row (or column).

Use this when candidate cells for a number in a row (or column) are concentrated within a single block.

In this row (or column), the number must definitely go somewhere in this block.

Therefore, you can remove that number from the candidate notes of "cells in other rows (or columns)" that are within the same block.

Common mistakes

Check where all candidates for the number occur. Pointing removes candidates outside the block; claiming removes them elsewhere inside it.
