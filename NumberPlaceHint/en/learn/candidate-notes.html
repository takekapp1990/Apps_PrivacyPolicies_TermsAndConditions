How to Use Candidate Notes

What candidate notes are and how to use them

TakeKApp · 2026-10-21

On this page

How it worksExampleCommon mistakes

How it works

When checking each cell, you often find multiple possible numbers. Because you cannot always decide immediately, writing possible numbers as notes helps you think through the puzzle. These are candidate notes.

As you write candidate notes in cells, if only one candidate remains, that cell is confirmed. If two or more remain, you use various techniques to reduce the candidates.

Once a cell's number is confirmed, you can remove that number from the candidate notes in the same row, column, and block. Removing candidates makes it easier to find the next confirmable cell.

Common mistakes

Candidate notes are possibilities, not confirmed numbers. Check the row, column and block and update notes after each placement.
