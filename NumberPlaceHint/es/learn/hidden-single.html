Cómo funciona

Busca una celda dentro de una fila, columna o bloque donde un número específico solo pueda encajar en un lugar.

Si solo hay una celda que puede contener un número particular, ese número está determinado para esa celda.

Ejemplo

Errores habituales

Revisa todas las casillas vacías del grupo. El número debe tener una sola posición posible.
