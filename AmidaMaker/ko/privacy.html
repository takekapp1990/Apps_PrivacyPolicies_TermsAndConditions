1. 기기에 저장하는 정보

참가자 이름, 결과·상품, 이름을 붙여 저장한 설정과 목록, 추첨 진행 상황과 최근 결과 최대 20건과 재생용 데이터, 언어·소리·테마 설정을 기기에 저장합니다. 광고와 일회성 광고 제거 구매에는 아래 외부 서비스를 사용합니다. 앱 품질 개선을 위해 이용 분석과 오류 진단에 Firebase를 사용합니다. 광고·구매 SDK도 서비스 운영에 필요한 정보를 처리합니다.

2. 공유와 문의

결과 카드 공유를 선택하면 OS 공유 기능을 통해 선택한 앱에 생성 이미지를 전달합니다. 이후 저장·전송은 공유 대상의 정책에 따릅니다. 참가자 이름 숨기기는 참가자 열만 변경하며 제목과 결과 문구는 변경하지 않습니다. 공유 전에 전체 내용을 확인하세요.

문의 내용은 메일 앱에서 확인 후 직접 전송합니다. 참가자나 상품 내용은 자동 첨부하지 않습니다. 문의로 받은 내용과 이메일 주소는 답변과 문제 조사에 필요한 범위에서 사용하며 처리 후 더 이상 필요하지 않은 정보는 삭제합니다.

3. 보관과 삭제

설정의 ‘저장 데이터 모두 삭제’로 저장 내용을 지울 수 있습니다. 앱 삭제 시 로컬 데이터가 삭제되지만 OS 백업과 이미 공유한 이미지는 별도로 관리됩니다. 다른 앱에 보낸 이미지는 본 앱에서 삭제할 수 없습니다. 생성 이미지는 OS 또는 공유 기능이 관리하는 임시 저장소에 남을 수 있습니다.

저장 데이터 삭제 후에도 표시 언어, 구매 권한, 광고 동의, 공유한 이미지는 유지됩니다. 외부 서비스에 이미 전송한 정보는 로컬 데이터 삭제로 삭제되지 않습니다.

4. 백업과 외부 사이트

Android 자동 앱 백업은 비활성화되어 있습니다. iOS 등의 백업에 앱 데이터가 포함되면 OS 설정에서 관리하세요. 외부 지원·스토어 사이트에 접속하면 해당 사이트가 접속 정보를 처리할 수 있습니다.

5. 변경과 연락처

데이터 처리 방식이 변경되면 본 방침과 관련 앱 내 설명을 갱신합니다. 개인정보 문의: takekapp1990@takekapp.com

6. 광고 및 선택 관리

무료 버전은 입력 화면에 Google AdMob 배너 광고를 표시하며, 추첨 결과를 확인한 후 입력 화면으로 돌아갈 때 전면 광고를 드물게 표시할 수 있습니다. 광고 제거 상품을 구매하면 두 종류의 광고가 모두 표시되지 않습니다. Google Mobile Ads와 UMP는 광고 제공·측정·부정 방지를 위해 IP 주소, 기기·광고 식별자, 광고 표시·상호작용, 진단 정보와 동의 상태 등을 처리할 수 있습니다. IP 주소로 대략적인 지역을 추정할 수 있습니다. 참가자 이름·상품·추첨 결과를 광고 SDK에 전달하지 않습니다.

지역과 설정에 따라 동의 화면이 표시됩니다. 변경 기능이 필요한 경우 설정에 ‘광고 개인정보 설정’이 표시됩니다. iOS 추적 허용은 OS 설정에서 변경할 수 있습니다. 거부해도 추첨 기능을 사용할 수 있습니다. 광고 제거 후 본 앱은 새 광고 요청을 하지 않지만 이전에 전송된 정보가 삭제되는 것은 아닙니다.

Google 정책: https://policies.google.com/privacy

7. 구매와 복원

Apple App Store / Google Play 및 RevenueCat을 통해 일회성 광고 제거 구매를 제공합니다. RevenueCat은 구매 확인·복원·부정 방지를 위해 무작위 앱 사용자 ID, 영수증·구매 토큰, 구매 내역, 광고 제거 권한, 기기·앱 정보 등을 처리합니다. 이름·이메일·입력 목록을 RevenueCat 사용자 속성으로 보내지 않습니다. 결제 정보는 스토어에서 처리하며 본 앱은 카드 번호를 받지 않습니다.

로컬 데이터 삭제는 스토어 거래 기록·구매 권한·외부 서비스 기록을 삭제하지 않습니다. 구매 데이터 조회·삭제 요청은 위 연락처로 문의하세요. 거래 유지 또는 법적 의무에 필요한 기록은 보관될 수 있습니다.

RevenueCat 정책: https://www.revenuecat.com/privacy

Apple 정책: https://www.apple.com/legal/privacy/

Google 정책: https://policies.google.com/privacy

8. 이용 분석과 오류 진단

품질 개선과 안정적인 운영을 위해 정식 버전은 시작 시 Firebase Analytics와 Crashlytics 전송을 자동으로 활성화합니다. 앱 내에는 전송을 켜고 끄는 설정이 없습니다. 광고 동의·추적 허용과 별개로 작동하며, 분석용 광고 식별자 수집과 광고 목적 데이터 사용은 비활성화합니다. Google은 이용 횟수, 광고 로드 성공·실패, 노출, 클릭, SDK가 제공하는 수익 정보, 앱·OS·기기 정보, 앱 인스턴스 등의 식별자, IP 기반의 대략적인 지역과 오류 스택을 처리합니다. 참가자 이름·상품·결과 본문, 공유 이미지, 별도 사용자 ID를 이벤트나 진단 속성에 추가하지 않습니다. Dart 예외 메시지는 고정 분류명으로 대체합니다. 네이티브 오류에는 SDK가 생성하는 진단 정보가 포함됩니다.

저장 데이터를 삭제해도 이미 전송된 정보는 삭제되지 않습니다. Google의 보관 기간은 서비스 설정과 정책을 따릅니다. 문의는 위 연락처로 보내 주세요.

Firebase 개인정보: https://firebase.google.com/support/privacy

9. 광고 게재 설정 가져오기

정식 버전은 광고 중단 등의 운영 설정을 가져오기 위해 Firebase Remote Config를 사용합니다. 이용 분석·오류 진단 전송과는 다른 목적으로 작동하며, Google은 Firebase 설치 ID 등 서비스 제공에 필요한 정보를 처리합니다. 설정을 가져올 때 참가자 이름, 상품, 추첨 결과를 전송하지 않습니다.

10. 사다리 추첨 방 관전

방을 열면 관전용 추첨판, 화면에 표시되는 참가자 이름과 아이콘, 공개 상품, 진행 상황과 공개된 결과를 Firebase Realtime Database로 전송합니다. 방 번호로 참여한 기기에 이 정보를 표시합니다. 방을 열거나 참여할 때 Firebase 익명 인증에서 발급한 식별자를 사용합니다. 방은 최대 2시간 동안 이용할 수 있으며 만료 후 방 데이터를 삭제합니다. 방 개설 보상 확인에는 AdMob의 서명된 알림과 보상 확인용 식별자를 사용합니다. 광고 숨기기 보상 만료 시각은 기기에 저장합니다.
