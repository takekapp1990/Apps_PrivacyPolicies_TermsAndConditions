นโยบายความเป็นส่วนตัว
ปรับปรุง: 12 พฤศจิกายน 2026
ผู้ให้บริการ: takekapp

1. ข้อมูลในอุปกรณ์
แอปบันทึกชื่อผู้เข้าร่วม ผลและรางวัล ชุดตั้งค่าและรายการที่ตั้งชื่อ ความคืบหน้า ผลที่เสร็จแล้วล่าสุดไม่เกิน 20 ครั้งพร้อมข้อมูลเล่นซ้ำ และตั้งค่าภาษา เสียง และธีมไว้ในอุปกรณ์ โฆษณาและการซื้อนำโฆษณาออกครั้งเดียวใช้บริการด้านล่าง Firebase ใช้วิเคราะห์การใช้งานและวินิจฉัยแอปขัดข้องเพื่อปรับปรุงคุณภาพ SDK โฆษณาและการซื้อประมวลผลข้อมูลที่จำเป็นต่อบริการด้วย

2. การแชร์และช่วยเหลือ
เมื่อเลือกแชร์การ์ดผล แอปส่งภาพไปยังแอปที่คุณเลือกผ่านระบบแชร์ของระบบปฏิบัติการ การจัดเก็บและส่งต่อเป็นไปตามนโยบายปลายทาง การซ่อนชื่อมีผลเฉพาะช่องผู้เข้าร่วม ไม่ซ่อนชื่อการ์ดหรือรางวัล ตรวจสอบทั้งการ์ดก่อนแชร์
ข้อความช่วยเหลือเปิดในแอปอีเมลให้คุณตรวจทานและส่ง โดยไม่แนบชื่อผู้เข้าร่วมหรือรางวัลอัตโนมัติ ข้อมูลและอีเมลที่ได้รับใช้ตอบคำถามและตรวจสอบปัญหา และลบเมื่อไม่จำเป็นหลังดำเนินการแล้ว

3. การเก็บและลบ
ใช้ลบข้อมูลที่บันทึกทั้งหมดในตั้งค่าเพื่อล้างเนื้อหาที่แอปบันทึก การถอนติดตั้งลบข้อมูลแอปในเครื่อง แต่ข้อมูลสำรองระบบและภาพที่แชร์จัดการแยกกัน แอปลบภาพที่ส่งไปแอปอื่นแล้วไม่ได้ ภาพที่สร้างอาจคงอยู่ในพื้นที่ชั่วคราวที่ระบบหรือฟังก์ชันแชร์จัดการ

4. ข้อมูลสำรองและเว็บไซต์ภายนอก
ปิดการสำรองแอปอัตโนมัติบน Android สำหรับ iOS และระบบอื่น ให้จัดการข้อมูลสำรองผ่านตั้งค่าระบบ เว็บไซต์ช่วยเหลือหรือสโตร์ภายนอกอาจประมวลผลข้อมูลการเข้าถึงเมื่อเปิดดู

5. การเปลี่ยนแปลงและติดต่อ
หากการจัดการข้อมูลเปลี่ยน เราจะปรับนโยบายและข้อมูลที่เกี่ยวข้องในแอป ติดต่อเรื่องความเป็นส่วนตัว: takekapp1990@takekapp.com

6. โฆษณาและตัวเลือก
เวอร์ชันฟรีแสดงแบนเนอร์ Google AdMob ในหน้าป้อนรายการ และอาจแสดงโฆษณาเต็มหน้าจอเป็นครั้งคราวเมื่อกลับหลังดูผล การซื้อนำโฆษณาออกครั้งเดียวจะนำออกทั้งสองรูปแบบ Google Mobile Ads และ UMP อาจประมวลผล IP ตัวระบุอุปกรณ์หรือโฆษณา การดูและโต้ตอบโฆษณา ข้อมูลวินิจฉัย และตัวเลือกความยินยอม เพื่อโฆษณา การวัดผล และป้องกันการฉ้อโกง โดยอาจอนุมานตำแหน่งคร่าว ๆ จาก IP แอปไม่ส่งชื่อผู้เข้าร่วม รางวัล หรือผลจับสลากไปยัง SDK โฆษณา
หน้าความยินยอมขึ้นกับภูมิภาคและการตั้งค่า หากมีตัวเลือกความเป็นส่วนตัวของโฆษณาในตั้งค่า จะเปลี่ยนตัวเลือกได้ สิทธิ์ติดตามบน iOS เปลี่ยนในตั้งค่าระบบ ปฏิเสธแล้วก็ยังจับสลากได้ การนำโฆษณาออกหยุดคำขอโฆษณาใหม่จากแอปนี้ แต่ไม่ลบข้อมูลที่ส่งไปแล้ว
นโยบาย Google: https://policies.google.com/privacy

7. การซื้อและกู้คืน
Apple App Store / Google Play และ RevenueCat ให้บริการซื้อนำโฆษณาออกครั้งเดียว RevenueCat ประมวลผล ID ผู้ใช้แอปที่สุ่มสร้าง ใบเสร็จหรือโทเคนการซื้อ ประวัติการซื้อ สถานะสิทธิ์ และข้อมูลอุปกรณ์/แอป เพื่อยืนยัน กู้คืน และป้องกันการฉ้อโกง เราไม่ส่งชื่อ อีเมล หรือรายการที่ป้อนเป็นคุณลักษณะผู้ใช้ RevenueCat สโตร์จัดการข้อมูลชำระเงิน แอปไม่ได้รับเลขบัตร
การลบข้อมูลในเครื่องไม่ลบบันทึกธุรกรรม สิทธิ์การซื้อ หรือบันทึกบริการภายนอก ติดต่ออีเมลข้างต้นเพื่อขอเข้าถึงหรือลบข้อมูลการซื้อ บันทึกที่จำเป็นต่อธุรกรรมหรือข้อกำหนดทางกฎหมายอาจยังเก็บไว้
นโยบาย RevenueCat: https://www.revenuecat.com/privacy
นโยบาย Apple: https://www.apple.com/legal/privacy/
นโยบาย Google: https://policies.google.com/privacy

8. วิเคราะห์การใช้งานและวินิจฉัยแอปขัดข้อง
รุ่นใช้งานจริงเปิดการรายงาน Firebase Analytics และ Crashlytics อัตโนมัติเมื่อเริ่มแอป เพื่อปรับปรุงคุณภาพและความน่าเชื่อถือ ไม่มีสวิตช์รายงานในแอป โดยแยกจากความยินยอมโฆษณาและสิทธิ์ติดตาม การเก็บ advertising ID และการใช้ข้อมูลวิเคราะห์เพื่อโฆษณายังปิดอยู่ Google ประมวลผลจำนวนการใช้งาน ผลการโหลดโฆษณา การแสดงผล การคลิก ข้อมูลรายได้จาก SDK ข้อมูลแอป/ระบบ/อุปกรณ์ ตัวระบุเช่น app instance ID ภูมิภาคคร่าว ๆ จาก IP และสแตกข้อขัดข้อง เราไม่เพิ่มชื่อผู้เข้าร่วม รางวัล ข้อความผล ภาพแชร์ หรือ ID ผู้ใช้กำหนดเองลงในเหตุการณ์หรือข้อมูลวินิจฉัย ข้อความข้อยกเว้น Dart แทนด้วยหมวดหมู่คงที่ การขัดข้องแบบ native มีข้อมูลวินิจฉัยที่ SDK สร้าง
การลบข้อมูลเกมไม่ลบข้อมูลที่ส่งแล้ว ระยะเก็บข้อมูลของ Google เป็นไปตามตั้งค่าและนโยบายบริการ ติดต่ออีเมลข้างต้นเพื่อสอบถาม
ความเป็นส่วนตัว Firebase: https://firebase.google.com/support/privacy

9. การดึงตั้งค่าโฆษณา
รุ่นใช้งานจริงใช้ Firebase Remote Config ดึงตั้งค่าการทำงาน เช่น หยุดโฆษณา ซึ่งมีจุดประสงค์แยกจากการวิเคราะห์และวินิจฉัย Google ประมวลผล Firebase installation ID และข้อมูลที่จำเป็นต่อบริการ การดึงตั้งค่าไม่ส่งชื่อผู้เข้าร่วม รางวัล หรือผลจับสลาก

10. ห้องชมอามิดะ
เมื่อเปิดห้อง แอปส่งกระดานสำหรับผู้ชม ชื่อและไอคอนที่แสดง รางวัลที่เห็น ความคืบหน้า และผลที่เปิดเผยไป Firebase Realtime Database เพื่อแสดงบนอุปกรณ์ที่เข้าด้วยรหัสห้อง แอปใช้ตัวระบุจาก Firebase Anonymous Authentication เมื่อเปิดหรือเข้าห้อง ห้องเข้าถึงได้สูงสุด 2 ชั่วโมง และลบข้อมูลหลังหมดอายุ รางวัลเปิดห้องใช้การแจ้งเตือน AdMob ที่ลงลายเซ็นและตัวระบุยืนยันรางวัล เวลาหมดอายุรางวัลปลอดโฆษณาบันทึกในอุปกรณ์
